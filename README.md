# 🗂️ PPM Workspace

> A clean, session-based **Project Portfolio Management** app built with Streamlit.  
> Manage projects, tasks, and teams — then export everything as JSON when you're done.

[![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat&logo=streamlit&logoColor=white)](https://streamlit.io)
[![Python](https://img.shields.io/badge/Python-3.9+-blue?style=flat&logo=python&logoColor=white)](https://www.python.org)
[![Pandas](https://img.shields.io/badge/Pandas-2CA02C?style=flat&logo=pandas&logoColor=white)](https://pandas.pydata.org)

---

## ✨ Features

| Module | What you can do |
|--------|-----------------|
| **Dashboard** | See total projects, tasks & teams at a glance + status bar chart |
| **Projects** | Create projects, assign teams & owners, update status |
| **Tasks** | Add tasks to projects, assign people, set due dates, mark complete |
| **Teams** | Create and manage teams (starts with "Personal") |
| **Portfolio** | High-level overview with task progress % and charts |
| **Backup** | One-click JSON export / import of your entire workspace |
